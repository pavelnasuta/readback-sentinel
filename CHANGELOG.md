# История изменений

Все заметные изменения ведутся здесь в формате, понятном продюсеру и разработке.

Правило: до merge каждого изменения создаётся отдельная заметка в `docs/releases/`. Этот файл содержит короткую навигацию по версиям.

## [Unreleased]

- Будущий server/cloud-контур остаётся в документации handoff и не реализован этим релизом.

## [0.5.0] — portable bootstrap

- Добавлен безопасный bootstrap с read-only проверкой, JSON receipt и явным подтверждением неэскалированных шагов установки.
- Локальная загрузка модели возможна только при явном `--model`; проверка и `--skip-model` модель не запрашивают.
- Добавлены инструкции для ручной настройки macOS/Homebrew, Ubuntu/Debian и Windows/winget, а также synthetic CI matrix.
- Алгоритмы QC, точность аудио-анализа, пороги и production server/cloud-контур не менялись.

Полное описание: [docs/releases/v0.5.0.md](docs/releases/v0.5.0.md).

## [0.4.1] — public project packaging

- Проект получил публичное имя **Readback Sentinel** и README с явным human-in-the-loop позиционированием.
- Добавлены MIT license, contribution guide, security/privacy policy и public-release boundary.
- Алгоритмы QC, пороги, модели и output-схемы не менялись.

Полное описание: [docs/releases/v0.4.1.md](docs/releases/v0.4.1.md).

## [0.4.0] — исправления безопасности и корректности

- Исправлены точные границы alignment, повторяющиеся anchor и числовые перечисления.
- Text/глоссарные результаты переведены в консервативные REVIEW-кандидаты с корректными диапазонами времени и поддержкой многословных glossary-вариантов.
- Все flag IDs проверяются на уникальность; просодика отделена в собственный namespace.
- Клиппинг проверяется на исходных каналах; тихие интервалы и последний RMS window больше не теряются.
- Псевдо-SNR/noise verdict отключён; просодика и PDF используют только нейтральные диагностические формулировки.
- Каждый прогон изолирован; manifest проходит `STARTED → COMPLETED/FAILED`.
- Confirmation связан с SHA-256 review snapshot и экспортирует финальные файлы без повторного ASR.

Полное описание: [docs/releases/v0.4.0.md](docs/releases/v0.4.0.md).

## [0.3.1] — модульный runtime-конвейер

- ASR, акустика и экспорты вынесены из CLI в отдельные тестируемые модули.
- Исправлена передача `RuntimeConfig` в акустическую и prosody-классификацию.
- Synthetic smoke подтвердил сохранение output-контракта относительно v0.3.0.

Полное описание: [docs/releases/v0.3.1.md](docs/releases/v0.3.1.md).

## [0.3.0] — конфигурируемое ядро и безопасное выравнивание

- Пороги и safety-policy из YAML теперь применяются и валидируются во время запуска.
- Добавлены core-модули config, normalization, alignment и manifest.
- Нормализация покрывает `ё/е`, Unicode, дефисы и базовые кардинальные числа до 999.
- Каждый успешный запуск формирует manifest с локальными SHA-256 и версиями конфигурации.

Полное описание: [docs/releases/v0.3.0.md](docs/releases/v0.3.0.md).

## [0.2.0] — безопасный триаж и честное выравнивание

- При неудачном выравнивании фрагмента текстовый diff больше не сравнивается с началом книги: создаётся `ALIGNMENT_FAILED`.
- DOCX-лист и финальные Audition-маркеры создаются только по явно подтверждённым ID из `--confirmed-flags`.
- Добавлены предварительные артефакты триажа: `triage_<tag>.docx` и `triage_markers_<tag>.csv`.
- Добавлена реальная поддержка DOCX-входа, проверка путей и корректная JSON-сериализация numpy-значений.

Полное описание: [docs/releases/v0.2.0.md](docs/releases/v0.2.0.md).

## [0.1.0] — baseline MVP

- Зафиксирован исходный конвейер: faster-whisper + text diff + базовый акустический анализ.
- Есть PDF, JSON, CSV для Audition, DOCX-лист перезаписи и транскрипт.
- Версия экспериментальная: флаги не должны уходить диктору без ручного триажа.

Полное описание: [docs/releases/v0.1.0.md](docs/releases/v0.1.0.md).

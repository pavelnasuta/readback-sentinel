# v0.5.0 — portable bootstrap

## Summary

v0.5.0 adds a minimal, receipt-driven bootstrap for macOS, Ubuntu/Debian, and Windows. Operators can perform a read-only prerequisite check, approve non-elevated dependency synchronization, and explicitly choose whether to prepare a local `tiny`, `base`, or `small` faster-whisper model. It also adds safe standard CUE sidecars as listening maps for preliminary and human-confirmed QC markers.

## What changed

- Added `scripts/bootstrap.py check --json` for dependency discovery with a single JSON receipt.
- Added approval-gated installation with locked `uv` synchronization and a smoke test after successful dependency setup.
- Added an explicit model helper and optional local cache selection. No model is requested without `--model`.
- Added standard CUE sidecars for preliminary review markers and human-confirmed markers. Preliminary CUEs retain the human-review boundary and omit ASR artifacts; confirmation CUEs contain only bound, explicitly confirmed IDs and neither form exposes transcript, printed-book text, or free-form descriptions.
- Documented manual package-manager actions, JSON receipts, and the privacy boundary.
- Added synthetic CI coverage on macOS, Ubuntu, and Windows with Python 3.11.

## Release boundary

This release improves bootstrap and safe review exports only. It does not improve audio-quality accuracy, revise QC thresholds, or establish evaluation metrics. It does not add a production model or server, queue, upload path, dashboard, or customer-data workflow.

All audio-quality candidates remain evidence for human review rather than automated narration verdicts.

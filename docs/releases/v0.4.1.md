# v0.4.1 — public project packaging

**Release type:** documentation and public-distribution packaging. No QC algorithm, threshold, model selection or output schema was changed.

## What changed

- The public project is branded **Readback Sentinel**.
- The README now documents the local-first workflow, human confirmation gate, repository map and limits.
- MIT licensing, contribution guidance, privacy/security policy and a public-release boundary were added.
- Public documentation explicitly distinguishes synthetic engineering tests from claims about real narration quality.

## What this does not claim

This release does not establish model accuracy, calibrated technical norms, reference-performance comparison, long-file readiness, Linux/server deployment or automatic acceptance of recordings.

## Verification

The existing synthetic suite passed before this documentation-only release. Public packaging does not substitute for a labelled real-audio evaluation.

## Rollback

Revert this release commit or check out `v0.4.0`. Neither rollback path changes any customer analysis artifact.
